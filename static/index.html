oder hierher ziehen

Word (.docx) oder LibreOffice/OpenOffice (.odt).

Die Datei bleibt auf diesem Rechner bzw. Server und wird nicht an Dritte weitergegeben.

Übersicht:

ODT Aus einer OpenDocument-Datei umgewandelt. Mimi prüft und korrigiert eine Word-Fassung davon. Am Ende bekommen Sie wieder eine OpenDocument-Datei (.odt) mit allen Korrekturen. Wo Mimi „in Word korrigieren“ schreibt, gilt das genauso für LibreOffice Writer. Bitte prüfen Sie das Layout im PDF.

Dokumenteigenschaften

Wird im PDF-Fenster statt des Dateinamens angezeigt und von Screenreadern vorgelesen.

Bestimmt die Aussprache im Screenreader. Fremdsprachige Passagen bitte in Word eigens markieren.

Links

Schriftfarben (Kontrast)

Text muss sich mit mindestens 4,5 : 1 vom weißen Hintergrund abheben (WCAG). Farbige Schrift in eingefügten Grafiken (z. B. rot/grün beschriftete Schemata) kann das Tool nicht prüfen – PAC prüft sie aber mit. Solche Grafiken in der Ursprungsdatei mit dunkleren Farben neu erstellen.

Bilder und Grafiken

Jedes Bild braucht einen Alternativtext, der den Inhalt kurz beschreibt – oder es wird als „dekorativ“ markiert (z. B. Zierlinien). Logos bekommen einen Text wie „Logo der …“.

Tabellen

Die erste Zeile mit den Spaltenüberschriften muss als Kopfzeile markiert sein (in Word: Tabelleneigenschaften → Zeile → „Gleiche Kopfzeile auf jeder Seite wiederholen“). Nur so erkennt PAC Tabellenköpfe.
